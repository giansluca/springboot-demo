    - docker push gianlucamori/springboot-demo:latest

    ** Grafana alloy + lgmt setup (https://hub.docker.com/r/grafana/otel-lgtm)
    The otel-lgtm image has an internal OpenTelemetry Collector that listens on port 4317.
    When Alloy sends data to lgtm:4317, that internal collector acts as a "sorting office" and automatically puts:
        - Logs into Loki.
        - Metrics into Prometheus.
        - Traces into Tempo.

    Otel is instrumented with opentelemetry java agent: java :path/to/opentelemetry-javaagent.jar -jar myapp.jar
        configuration by environment variables:
        OTEL_SERVICE_NAME=springboot-demo
        OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
        OTEL_EXPORTER_OTLP_PROTOCOL=grpc
        OTEL_RESOURCE_ATTRIBUTES=deployment.environment=local,service.namespace=black-bull
        JAVA_TOOL_OPTIONS="-javaagent:dev-tools/opentelemetry-javaagent.jar"
